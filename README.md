# OpenDCL community

**New OpenDCL questions and wishlist items live here** via [GitHub Discussions](https://github.com/opendcl/community/discussions).

| Need | Where |
|------|--------|
| Ask a question | **[Q&A](https://github.com/opendcl/community/discussions/new?category=q-a)** |
| Wishlist (new capability) | **[Wishlist](https://github.com/opendcl/community/discussions/new?category=ideas)** |
| Report a bug | [opendcl/OpenDCL Issues](https://github.com/opendcl/OpenDCL/issues/new?template=bug.yml) |
| Historic forum (2007–2026) | **[Forum archive](https://opendcl.github.io/forum-archive/)** (read-only, searchable) |
| Source code | [opendcl/OpenDCL](https://github.com/opendcl/OpenDCL) |
| Downloads & help | [opendcl.github.io](https://opendcl.github.io/) |
| Community chooser | [www.opendcl.com/forum](https://www.opendcl.com/forum/) |

Do **not** file product bugs in this repository. Issues are disabled here on purpose.

## How to post

1. Open the [community chooser](https://www.opendcl.com/forum/) or pick a row in the table above.
2. For support, use **Q&A**. For something OpenDCL cannot do today, use **Wishlist**.
3. Prefer a clear title and CAD host/version when relevant (AutoCAD, BricsCAD, etc.).

Please **do not** open pull requests in this repository for product source—use [opendcl/OpenDCL](https://github.com/opendcl/OpenDCL).

## Legacy forum

The legacy SMF forum has been **decommissioned**. The [www.opendcl.com/forum](https://www.opendcl.com/forum/) URL now serves a GitHub Pages chooser (with redirects for old topic/board links). History is preserved in the [forum archive](https://opendcl.github.io/forum-archive/).
