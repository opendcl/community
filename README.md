# OpenDCL community

**New OpenDCL questions and conversation live here** via [GitHub Discussions](https://github.com/opendcl/community/discussions).

| Need | Where |
|------|--------|
| New Q&A and chat | **[Discussions](https://github.com/opendcl/community/discussions)** |
| Historic forum (2007–2026) | **[Forum archive](https://opendcl.github.io/forum-archive/)** (read-only, searchable) |
| Bugs / defects | [opendcl/OpenDCL Issues](https://github.com/opendcl/OpenDCL/issues) |
| Source code | [opendcl/OpenDCL](https://github.com/opendcl/OpenDCL) |
| Downloads & help | [opendcl.github.io](https://opendcl.github.io/) |

## How to post

1. Open [Discussions](https://github.com/opendcl/community/discussions).
2. Choose a category (use **Q&A** for support questions when possible).
3. Prefer a clear title and CAD host/version when relevant (AutoCAD, BricsCAD, etc.).

Please **do not** open pull requests in this repository for product source—use [opendcl/OpenDCL](https://github.com/opendcl/OpenDCL).
